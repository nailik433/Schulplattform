🧪 KI & API

So lässt du dir von Claude interaktive Lernumgebungen bauen – und direkt in die Klasse legen.

1. Cowork / claude.ai: Connector einmal hinzufügen (empfohlen)

Danach hat Claude in Cowork fertige Werkzeuge („Klassen auflisten", „Lernumgebung anlegen", …) und schreibt Lernumgebungen direkt in deine Klasse – ohne Kopieren, ohne Chrome.

Deine persönliche Connector-URL (enthält deinen Schlüssel – nicht weitergeben):

  1. In Claude: Customize → Connectors → Add custom connector
  2. Name: Schulplattform · URL: die kopierte Adresse einfügen · Hinzufügen
  3. In Cowork im Chat sagen: „Zeig mir meine Klassen" – fertig.

Für Claude Code / Claude Desktop gibt es zusätzlich einen lokalen Connector: Anleitung. Ohne Connector funktioniert in Cowork auch das Cowork-Briefing (API).

2. Prompt für einen normalen Claude-Chat

Ohne Connector: Prompt kopieren, [BESCHREIBUNG] ersetzen, HTML-Ausgabe unter „+ Lernumgebung" einfügen.

3. API-Schlüssel & HTTP-API

Dein API-Schlüssel (geheim halten!):

{% csrf_token %}

Basis-URL: {{ base_url }} · Header X-API-Key oder Authorization: Bearer

# Klassen (mit IDs) abrufen:
curl -H "X-API-Key: {{ api_key.key }}" {{ base_url }}/api/classes

# Lernumgebungen einer Klasse auflisten:
curl -H "X-API-Key: {{ api_key.key }}" "{{ base_url }}/api/lessons?class_id=1"

# Lernumgebung anlegen (zum Aktualisieren zusätzlich "id": <lesson-id>):
curl -X POST {{ base_url }}/api/lessons \
  -H "X-API-Key: {{ api_key.key }}" \
  -H "Content-Type: application/json" \
  -d '{"class_id": 1, "title": "Magnetismus", "html": "<!DOCTYPE html>..."}'
