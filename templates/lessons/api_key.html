KI-Schnittstelle & Prompt

So lässt du dir von Claude interaktive, animierte Lernumgebungen bauen und bringst sie in die Plattform.

Empfohlen: direkt aus Cowork oder Claude Code

Am bequemsten lässt du Claude die Lernumgebung direkt in die Klasse schreiben – ohne Kopieren:

  • Cowork: das Cowork-Briefing in die Projekt-Anweisungen einfügen und deinen API-Schlüssel (unten) eintragen.
  • Claude Code / Claude Desktop: den MCP-Connector einmal registrieren – dann hat Claude fertige Werkzeuge („Klassen auflisten", „Lernumgebung anlegen").

1. Lernumgebung von Claude bauen lassen

Kopiere diesen Prompt in einen Claude-Chat und ersetze [BESCHREIBUNG].

2. In die Plattform bringen

Einfachster Weg: Claudes HTML-Ausgabe kopieren → in einer Klasse auf „+ Lernumgebung" → HTML einfügen → Erstellen. Fertig.

Oder automatisch über die API (für Fortgeschrittene) – siehe unten.

3. API (optional, automatisiert)

Dein API-Schlüssel (geheim halten!):

{% csrf_token %}

Basis-URL: {{ base_url }}

# Klassen (mit IDs) abrufen:
curl -H "X-API-Key: {{ api_key.key }}" {{ base_url }}/api/classes

# Lernumgebung anlegen:
curl -X POST {{ base_url }}/api/lessons \
  -H "X-API-Key: {{ api_key.key }}" \
  -H "Content-Type: application/json" \
  -d '{"class_id": 1, "title": "Magnetismus", "html": "<!DOCTYPE html>..."}'
